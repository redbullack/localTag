# Antigravity Blueprint: Tag-based File Organizer (Next.js + Electron + SQLite)

## 1. 프로젝트 목적
이 앱은 단일 폴더의 한계를 극복하기 위해 만들어진 데스크톱 파일 정리 앱입니다. 사용자는 물리적인 폴더 이동 없이, 무한한 계층의 '태그(Tag)'를 조합하여 원하는 파일을 즉각적으로 찾고 관리할 수 있습니다. 

## 2. 코어 아키텍처 (기술 스택)
* **프론트엔드 (Renderer Process):** Next.js, React (UI 렌더링 및 상태 관리)
* **백엔드/시스템 (Main Process):** Electron (로컬 파일 시스템 제어, OS 네이티브 기능)
* **데이터베이스:** SQLite (로컬 임베디드 DB, 앱 내장)
* **통신 방식:** Electron IPC (Inter-Process Communication)를 통한 Main-Renderer 안전한 통신

## 3. 핵심 비즈니스 로직 및 규칙
* **단일 루트 폴더 (Vault):** 사용자가 앱에 등록하는 모든 파일은 지정된 하나의 로컬 '루트 폴더'로 모입니다.
* **중복 파일명 방지:** 루트 폴더 내 파일명은 고유해야 합니다. 파일 추가 시 이름이 겹치면 UUID로 강제 변경하지 않고, 사용자에게 팝업을 띄워 직접 이름을 수정하도록 유도하는 직관적인 UX를 제공합니다.
* **데이터 구조:** SQLite에는 실제 파일이 아닌 '파일의 이름(루트 폴더 기준 경로)'과 '태그 정보(이름, 색상, 계층형 부모/자식 관계)', 그리고 이 둘의 다대다(N:M) 매핑 정보만 가볍게 저장합니다.
