# Antigravity UI Polish: Design System & Styling Rules

## 1. 디자인 철학 (Discord Style)
* **고밀도 레이아웃:** 화면 좌우 공백을 최소화하고, 창 전체를 데이터로 꽉 채워 한눈에 많은 파일과 태그를 볼 수 있게 구성합니다.
* **상단 고정 메뉴바:** 네비게이션과 주요 액션은 화면 상단 메뉴바에 고정하여 항상 접근 가능하게 합니다.

## 2. 테마 및 색상 규정 (Strict Theming)
* **지원 모드:** Light 모드, Dark 모드, OS System 모드를 완벽하게 지원해야 합니다.
* **가시성 최우선:** 텍스트, 배경, 컴포넌트 경계선의 대비(Contrast)를 명확히 하여 가독성을 극대화합니다. 지저분하거나 묻히는 색상 배치는 엄격히 금지합니다.
* **CSS 적용 규칙:** 코드를 작성할 때 항상 다크/라이트 모드 양쪽의 CSS 변수(또는 Tailwind 클래스)를 동시에 고려하여 작성하세요.

## 3. 컴포넌트 개발 규칙
* **모듈화 및 재사용:** Select Box, Card, Check Box, Input Box, DataGrid, Chart, Modal 등의 UI 요소는 반드시 개별 폴더에 커스텀 컴포넌트로 분리하여 구축합니다.
* **레이아웃 붕괴 방지:** 윈도우 창 크기를 조절하거나 데이터가 길어져도 `<div>` 요소들이 겹치거나 원치 않게 밀려나는 현상(Layout Shift)이 없도록 Flexbox와 Grid를 견고하게 설계하세요.
* **유지보수성:** 기능 확장을 고려하여 컴포넌트의 Props를 직관적이고 간결하게 설계하세요.
