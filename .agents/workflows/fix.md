# Antigravity Fix: Debugging & Issue Resolution

에러 발생 시 다음 절차를 따르세요:

1.  **에러 위치 격리:** 문제가 Next.js(브라우저 콘솔, 렌더링 오류)에서 발생했는지, Electron(터미널, 로컬 파일 시스템 오류)에서 발생했는지, SQLite(쿼리 구문 오류, 락킹 오류)에서 발생했는지 먼저 식별하세요.
2.  **UI 레이아웃 버그:** 컴포넌트가 겹치거나 깨지는 버그를 수정할 때는, 강제적인 `margin`이나 고정 `px` 높이를 남발하지 말고 Flex/Grid 구조의 본질적인 원인을 찾아 해결하세요.
3.  **파일 시스템 예외 처리:** 권한 문제, 파일 사용 중(Lock), 디스크 용량 부족 등 로컬 환경에서 발생할 수 있는 엣지 케이스를 항상 염두에 두고 방어적인 코드(`try-catch`)를 작성하세요.
